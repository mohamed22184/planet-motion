# ae — موكابات After Effects

مكان الموكابات اللي بنطلّع منها منحنيات الحركة قبل ما نكتبها في
الموقع. الـspec في `docs/motion-system.md`.

| الملف | إيه ده |
|---|---|
| `scene.mjs` | الهندسة المشتركة: الكروت ومعادلات الكاميرا، مقروءة من `work.ts` |
| `build-assembly.mjs` | بيولّد موكاب **التجميع** |
| `build-open.mjs` | بيولّد موكاب **فتح المشروع** |
| `assembly-mockup.jsx` · `open-mockup.jsx` | **متولّدين** — بيبنوا الكومبات في AE |
| `*.aep` | المشاريع نفسها — **مش في الريبو** (`.gitignore` بيستثني `*.aep`). بتتولّد من السكربتات في تانية |
| `frames/` | فريمات مرجعية من الكومبات |
| `read-ease.jsx` | بيقرا منحنيات الكيفريمات ويطلّعها CSS + GSAP CustomEase |
| `ease-export.txt` | آخر ناتج من `read-ease.jsx` |

## الشغل عليه

```sh
node ae/build-assembly.mjs      # لو غيّرت الشغل في work.ts
```

```sh
node ae/build-open.mjs
```

وبعدين في AE: **File ▸ Scripts ▸ Run Script File** ▸ `ae/assembly-mockup.jsx`
أو `ae/open-mockup.jsx`.
تشغيله تاني بيعيد بناء الكومب بنفس الاسم — مش بيعمل نسخة تانية، ومش
بيلمس أي حاجة تانية في المشروع.

ظبّط اللي عايزه في الـGraph Editor، وبعدين شغّل `read-ease.jsx`:
بيطلّعلك `cubic-bezier(...)` و`CustomEase.create(...)` جاهزين للنقل،
وبيكتبهم كمان في `ease-export.txt`.

## الهندسة مش تقريبية

الكومب 1440×810 @25 — نفس مرجع الموقع (`fit = 1` عند 1440).
والكاميرا مبنية على نفس معادلات `index.astro`:

| الموقع (CSS) | AE |
|---|---|
| `perspective: 900px` | Camera Zoom = 900 |
| `translateZ(d)` على العالم | الكاميرا على بعد `900 − d` من الهدف |
| z سالب = بعيد | z موجب = بعيد (`z_ae = −z_css`) |
| تكبير العنصر = `900 / (900 − z)` | نفسها، من الـzoom والمسافة |

فالكروت في الكومب في نفس أماكن الموقع بالظبط، واللقطة الواسعة
متحسوبة بنفس `computeWide()`.

**مقيس:**

| | AE | المتصفح |
|---|---|---|
| الريل في لقطة الفتح (التجميع) | 1381px عرض | — (محسوبة: `900/430 × 660`) |
| الكارت وقسمه مركّز عليه (الفتح) | 200, 45 · 597×357 | **196, 56 · 593.5×354.1** |
| الهيرو بعد المورف | 37, 71 · 1106×624 | **40, 74 · 1100×618.8** |

الفرق في مستطيلات الفتح هو عرض البرواز نفسه (الـstroke بيتحسب في
الصندوق المرسوم ومابيتحسبش في `getBoundingClientRect`)، والإزاحة
الرأسية في لقطة البداية من انجراف كاميرا الموقع البطيء (±1.1°).
و16 كارت كلهم جوّه الفريم في اللقطة الواسعة.

## اختبار الاتجاهين

الموكاب بيتبني بمنحنى الموقع نفسه `cubic-bezier(.16, 1, .30, 1)`
مترجم لمفردات AE (سرعة + تأثير). لو شغّلت `read-ease.jsx` على
كومب لسه ماتعدّلش فيه، لازم يرجّع نفس الأربع أرقام. لو رجّع غيرها،
التحويل مكسور — مش الحركة.
